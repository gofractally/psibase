Which hidden password fields does your password manager fill?

This page is only a test. It helps choose how the sign-in page keeps its password field out of sight for people who do not need one. Nothing typed here is sent anywhere or used for an account.

1. Save a test entry

Press Save test entry and let your password manager save it (user name field-test). If it does not offer to, add an entry for this site by hand with that user name and any password.

Test entry

2. Reload this page, then press Check

After reloading, give the manager a moment (or use its fill button if it has one), then press Check. Each box is a login form whose password field is hidden a different way.

Copy the result box and send it back, saying which password manager and browser you used.
